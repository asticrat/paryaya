For developers

Three steps. That's it.

Your users never touch a Paryaya interface — your app talks to our API. That's the whole model.

Get Your API Key

Sign up and receive your sk-paryaya-xxxx key instantly. One key is all you need.

Call the API from Your App

Make a simple HTTP request — send audio bytes or a file. Works from any language. Real-time streaming via WebSocket, or batch via REST.

Get Nepali Text Back

Your app receives Devanagari transcript in milliseconds. Drop it into your call center software, banking app, or hospital system.
